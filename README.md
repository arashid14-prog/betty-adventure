# Betty Adventure

**Created by:** Afia Rashid

A small arcade platform game made with Python and Tkinter. Play as a pixel-art cat, stomp green slimes, collect coins, and find the way home.

## Goal

Collect at least 8 of the 12 coins, then enter the little cat house at the far right. You have three lives. Falling or touching a slime costs one life; jump on a slime to defeat it.

## Controls

- **A / D** or **Left / Right arrows** — move
- **Space** or **Up arrow** — jump
- **Enter** — start or restart

## Run

Requires Python 3 with Tkinter (included with most desktop Python installations). No extra packages are needed. Keep the `assets` folder beside `skybound.py`.

```bash
python skybound.py
```

On Windows, `py skybound.py` also works. Click the game window before playing if the keyboard does not respond.
